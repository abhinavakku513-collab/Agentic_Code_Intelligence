Synthetic commit demo mutator

Changes N units of the latest version with Apps-Evolve's synthetic edit operators (rename, constant, branch, comment, reformat, reorder) and builds the result as the next version. It demonstrates incremental rebuilds; it is not ingestion of a real commit. Real repositories are ingested with acis ingest --kind git.
