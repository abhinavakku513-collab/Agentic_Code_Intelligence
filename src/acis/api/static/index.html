Guarantees each enforced by automated tests

  • No generation. Every result is stored code, re-read from the content store by its hash.
  • Exact search. The dense channels score every unit (one matrix product), with no approximate index to miss one.
  • Version isolation. A query is answered from exactly one immutable snapshot; caches are keyed by snapshot and config.
  • Batch invariance and determinism. A query's ranking never depends on other queries; same inputs give the same ranking.
  • Offline. No network, no API keys, no GPU at query time.
  • Honest evaluation. Rankers are scored out of fold; every metric shown here cites its ledger row, and the ledger is hash-chained.
