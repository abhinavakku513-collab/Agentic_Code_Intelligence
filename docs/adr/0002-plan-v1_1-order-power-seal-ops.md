# ADR-0002 — Plan v1.1: phase order, gate power, physical seal, long jobs, demo scope
Status: **accepted 2026-09-20** (owner instructed the kit to be updated per `docs/reference/ACIS_Kit_Audit_and_Winning_Plan.md`; revert by superseding ADR).

**Context.** The v1.0 kit had (B1) unverified hook wiring, (B2) a regex-only "seal" with reproducible bypasses, (B3) the irreversible TEST run in the allow path, (B4) no procedure for hours-long or GPU jobs, (B5) an order that put the largest lever (adaptation) fourth and shipped a BM25 RC0, (B6) gates on ≈ 1,000 queries that cannot see 0.5–1 pt gains, plus spec bugs (INV-10 vs small fixtures, TEST budget arithmetic, G0.6 undefined, D1 using TEST queries).

**Decision.** Adopt `docs/spec/09` §1–§6: phases 0–5 + Track B (B1–B4) + Phase 6; RC0 = best frozen dense, Mode B; adaptation in Phase 3 with GPU hand-off; gates on all 5,000 TRAIN queries (non-fit components) or K-fold OOF (trained), DEV-H = once-per-milestone confirmation; physical seal (`~/.acis-sealed/`, separate `HF_HOME` for the official run); `ask` rules on TEST-touching commands and owner-launched official runs; `scripts/run_detached.sh` for jobs > ~10 min; TEST budget 6 (RC0 ×1, RC1 ×2, contingency ×2, post-hoc clean-pool ×1); `min(top_k, N)`; D1 on held-out folds; config paths from the repo root; PPT and demo video are owner-made (Claude Code builds `make demo` + evidence files). Hook commands use the string form and are proven by `/canary` (G0.0).

**Evidence.** [EXEC] `tests/security/test_guard_hook.py`: v1.0 guard 11 failures → v1.1 40 pass + 3 documented gaps (`xfail(strict)`), re-run independently when the kit was merged. [EXEC] `tests/contract/test_score_ties.py` 19 pass. [SIM] gate power (spec 09 §2; CI half-width ≈ 1 pt at n = 1,000, ≈ 0.43 pt at n = 5,000; simulation assumptions: 12 % of queries move ±0.45, paired SD ≈ 0.16 — re-estimate from real runs). [READ] spec-bug list. [E] GPU-hours (`docs/GPU_HANDOFF.md`).

**Consequences.** Better power and earlier shippable floor (F1); Track B runs in parallel; more owner actions (canary, launching official runs, GPU hand-off); TEST labels need a one-time manual fetch into `~/.acis-sealed/`. **Risk**: the HF cache layout is unverified [U] → verified in G0.6. **Rollback**: supersede with an ADR restoring the v1.0 order and gates.
