# Development history

Reports written during development, phase by phase (P0 harness, dense engine, P1 store, Bonus lineages, demo) and the
acceptance report of the pass before the final one. They are kept as a record of how each component was verified;
their numbers cite ledger rows in `runs/ledger.jsonl`. They refer in places to internal planning files that are not part
of the published repository. The current system and its results are described in the top-level `README.md`.
